# CI/CD веб-версии

Рабочая ветка публикации — `web-port`. Push запускает `.github/workflows/web.yml`:
API-тесты, 16 сценариев очереди, Android compile/unit, production Wasm, упаковку и
совместный HTTP-тест двух клиентов. PR проверяется без публикации и секретов.
После успешной проверки создаётся публичный prerelease `web-build-<SHA>` с архивом.

Debian проверяет текущую ветку и успешный run GitHub Actions, затем загружает пакет,
сверяет манифест и собирает production-образ. Все автотесты выполняются в GitHub CI;
на Debian остаются только проверки успешности установки. До обновления создаётся
согласованная копия SQLite. Новый API должен стать healthy, затем атомарно меняется
симлинк статики. При неуспешной HTTPS-проверке возвращаются прежние образ и статика.
Откат схемы БД автоматом не выполняется: миграции должны быть обратно совместимыми.

Секреты GitHub и входящий SSH для CI не требуются. Сервер опрашивает Git каждую
минуту, API GitHub для ожидающего релиза — не чаще раза в 5 минут (лимит запросов).
Ошибка CI не публикуется. БД, резервные копии и логи в публичный архив не входят.

На Debian: `/home/lemonke67/finney`. `compose.yaml`, `nginx.conf`, скрипты `ops/`
устанавливаются туда администратором отдельно; изменение этих файлов не применяется
пакетом автоматически. Код API и статика обновляются автоматически.
Traefik доверяется по имени контейнера; при смене его IP перезапустить web.
API доступен только в отдельной внутренней сети через nginx.

Ежедневная копия: `backup_daily.py`, 14 ежедневных и 20 последних преддеплойных.
Копии на том же SSD защищают от ошибок обновления, но не отказа SSD; внешний
зашифрованный бэкап настраивается отдельно. Перед ручным восстановлением остановить
API и убрать прежние WAL/SHM вместе с прежней БД; порядок — в эксплуатационном runbook.

Автотесты запускаются только с временной БД. Для ручного совместного теста:
`FINNY_LIVE_TEST=1 ./gradlew -p deploy/client-tests test` при локальном стенде
`deploy/dev_server.py` на 127.0.0.1:18086. Обычный запуск без стенда пропускает
только совместный HTTP-тест.
