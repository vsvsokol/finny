# Учётные записи и серверные сохранения веб-версии

Веб-клиент работает с API того же origin по `/api/`. Учётная запись — логин-псевдоним
и пароль без почты. У одной учётки несколько питомцев. Вход и регистрация находятся
в верхней панели «Войти / сохранения»; без входа остаётся гостевой режим.

## Что сохраняется

- Гость использует прежний ключ `finny.games`. Сервер его не читает.
- Для учётки используются отдельные ключи `finny.account.<id>.state` и
  `finny.account.<id>.activeProfile`. Пароль, cookie и код восстановления туда не пишутся.
- На сервер передаются только обычные профили. Демо остаётся локальным.
- Перенос гостевых питомцев предлагается явно в меню учётки и выполняется один раз
  для этой учётки. Исходные гостевые данные сохраняются в браузере.
- В игре локальный id стабилен; серверный id хранится в таблице соответствий.
  При обмене все `profileId` переназначаются согласованно. Это сохраняет выбранного
  питомца при первом отправлении нового офлайн-профиля.

## Офлайн и конфликты

Состояние и очередь записываются одним документом localStorage до обновления Flow.
Запрос фиксируется до отправки, включая тело и случайный Idempotency-Key. Потерянный
ответ не создаёт дубликат: повтор использует тот же запрос. Изменения во время
отправки остаются в очереди следующей ревизии. При ошибке записи локального кэша
игра показывает ошибку и не принимает новое состояние как сохранённое.

При конфликте можно взять серверную версию или сохранить обе версии отдельными
питомцами. Перед выбором снимки добавляются в местную резервную копию, доступную
для скачивания в меню учётки. Клиент не объединяет расходы двух устройств и
не перезаписывает серверную версию по часам устройства. Удалённый профиль можно
вернуть только новой копией с новым серверным id.

Выход сохраняет неотправленную очередь для следующего входа в ту же учётку.
Переход между учётками перезапускает клиент; ожидаемая учётка проверяется API.
Для записи используется одна вкладка на origin: Web Locks блокирует вторую вкладку
до закрытия первой. При отсутствии Web Locks клиент просит обновить браузер.

`?reset=1` сбрасывает только гостевую копию, если не выбрана учётная запись.
Он не удаляет серверные профили, локальную очередь учётки или её резервные копии.

Для повторного открытия без сети нужен готовый кэш статики. Индикатор «Офлайн ✓»
появляется после установки service worker. Первый визит требует сети. API,
авторизация и снимки не кэшируются worker: они находятся только в локальном
состоянии учётки и на сервере. Новая версия worker активируется после закрытия
старых вкладок, чтобы не смешивать файлы двух сборок.

## Сборка и упаковка

Из репозитория игры:

```bash
./gradlew :web:wasmJsBrowserDistribution
```

Готовый каталог `web/build/dist/wasmJs/productionExecutable` затем нужно упаковать
скриптом `server-project/finney-web/prepare_release.py` в **новый** каталог:

```bash
python3 /путь/к/server-project/finney-web/prepare_release.py \
  web/build/dist/wasmJs/productionExecutable /путь/к/новому-релизу
```

Скрипт создаёт `sw.js` с полным списком ресурсов, отдельным именем кэша и
`release.json` с контрольными суммами. Публикуется упакованный каталог целиком.
Source maps не включаются в пакет. При первом заполнении кэша worker заранее
скачивает все ресурсы; это приблизительно размер полной игры.

Сервер должен выдавать корректные MIME `.wasm`, `.js`, `.css` и регулярно проверять
обновление `sw.js`/HTML. Не направлять `/api/` на HTML игры. Подробный контракт,
запуск API и тесты — в `server-project/finney-web/README.md`.

## Изменённые части

- `CloudSync.kt` — переносимая машина очереди, ревизий, соответствий id и конфликтов.
- `CloudBrowser.kt` — fetch, Web Locks, скачивание копии. JSON игры не разбирается
  в JavaScript, чтобы не потерять точность 64-битного seed.
- `WebAccount.kt` — учётка, кэш, жизненный цикл синхронизации и связь с формами.
- `account.js`/`account.css` — нативные формы для доступности и менеджеров паролей.
- `WebGameStorage`, `WebPrefs`, веб-`AppContainer`, `main.kt` — подключение к кэшу
  и переоткрытие стартового экрана при получении/удалении профиля с сервера.

Общие исходники Android и игровая экономика не менялись.
